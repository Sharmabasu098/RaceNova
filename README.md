# 🏎️ RaceNova

> **RaceNova** is an open-source 3D arcade racing game built with **Three.js** and **Vite**. Experience fast-paced racing, master drifting and nitro, upgrade your cars, and explore unique worlds. Designed for Web first, with future support for Android and Pi App Studio.

---

# 🎮 About

RaceNova is a modern arcade racing game focused on smooth controls, exciting gameplay, and optimized performance. The project is being developed from scratch as an open-source learning and game development journey.

---

# ✨ Features

- 🚗 Fast-paced 3D Arcade Racing
- 🌍 Multiple Unique Worlds
- 🏁 Career Mode
- 🚦 AI Drivers & Traffic System
- ⚡ Nitro Boost
- 💨 Drift Mechanics
- 🔧 Car Upgrade System
- 🎨 Car Customization
- 💾 Save Progress
- 📱 Mobile-Friendly Design
- 🌐 Web Version
- 🟢 Future Pi App Studio Support
